# 🛡️ Wazuh SOC Home Lab

A hands-on Security Operations Center (SOC) home lab built to demonstrate
security monitoring, attack simulation, alert investigation, MITRE ATT&CK
mapping, and incident response using Wazuh.

## 🎯 Objective

The objective of this project is to build a practical SOC environment
using virtual machines and security tools to simulate common security
events and practice the workflow followed by a SOC analyst.

The project focuses on:

- Security event monitoring
- Authentication attack detection
- Network reconnaissance
- Log analysis
- File Integrity Monitoring
- Malware simulation
- MITRE ATT&CK mapping
- Alert investigation
- Incident response
- Security documentation
